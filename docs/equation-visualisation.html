3  Age-dependent demographic schedules and ecological weights

This chapter visualises the age-dependent functions used by the Household Demography model. Its purpose is diagnostic rather than inferential: the plots show the shapes produced by the model equations and make the consequences of changing their parameters easier to inspect.

Three distinct components are considered:

  1. the Peristera–Kostaki function used for annual fertility and union-formation schedules;
  2. the Coale–Demeny model life tables used for age- and sex-specific mortality;
  3. the schematic adult-equivalent weights used for subsistence demand and labour availability.

The first two components define event probabilities. The demand and labour functions instead assign relative weights to individuals according to age. None of the illustrative parameter sets below should be interpreted as calibration to a particular historical population.

3.2 Peristera–Kostaki schedules

The Peristera–Kostaki function is:

\[ f_{\mathrm{PK}}(x) = c_1 \exp\left[ -\left( \frac{x-\mu}{\sigma(x)} \right)^2 \right], \qquad \sigma(x) = \begin{cases} \sigma_1, & x \leq \mu,\\ \sigma_2, & x > \mu. \end{cases} \]

Here, (c_1) controls the maximum probability, () the modal age, and (_1) and (_2) the spread before and after the mode. The same functional form is used for fertility and union formation, with separate parameterisations.

Code 
pk_probability <- function(
  age,
  c1,
  mu,
  sigma1,
  sigma2
) {
  sigma <- if_else(age <= mu, sigma1, sigma2)

  c1 * exp(
    -((age - mu) / sigma)^2
  )
}

generate_pk_schedule <- function(
  c1,
  mu,
  sigma1,
  sigma2,
  max_age = 100
) {
  tibble(age = 0:max_age) |>
    mutate(
      probability = pk_probability(
        age,
        c1,
        mu,
        sigma1,
        sigma2
      )
    )
}

The vectorised function returns a tidy table rather than growing a vector inside a loop. This makes it easier to generate, combine, and label multiple schedules.

Code 
pk_profiles <- tribble(

3.3 Coale–Demeny mortality schedules

The Coale–Demeny component supplies grouped probabilities of dying for four regional model families, two sexes, and 25 mortality levels. The model workflow converts these grouped schedules to annual lookup vectors with the same interpolation used when producing the NetLogo input tables.

Code 
read_cd_schedule <- function(
  region = "w",
  sex = "F",
  level = 8,
  table_directory = "../demoTables",
  max_age = 100
) {
  if (!region %in% c("w", "e", "s", "n")) {
    stop("region must be one of: w, e, s, n.")
  }

  if (!sex %in% c("F", "M")) {
    stop("sex must be F or M.")
  }

  if (!level %in% 1:25) {
    stop("level must be between 1 and 25.")
  }

  mortality_table <- read.table(
    file.path(
      table_directory,
      paste0("cdmlt", region, sex, ".txt")
    ),
    header = TRUE,
    check.names = FALSE
  )

  data.frame(
    region = region,
    sex = sex,
    level = level,
    age = mortality_table$age,
    probability =
      mortality_table[[as.character(level)]]
  ) |>
    dplyr::filter(age <= max_age)
}

The interpolation helper intentionally reproduces the lookup construction used by the model workflow. Its purpose here is visual consistency with the probabilities imported by NetLogo, rather than reconstruction of an alternative continuous mortality model.

For the manuscript figure, a single regional family and sex are held constant while mortality level varies. This produces a more legible comparison than changing region, sex, and level simultaneously.

3.5 Age-weighted demand and labour

Versions v1.2.1 and v1.4.1 replace head count with age-weighted subsistence demand. Versions v1.2.2 and v1.4.2 add an age-weighted labour contribution. Both functions equal one between the lower and upper adult-equivalent breakpoints, (x_m=15) and (x_s=45), but use different exponents outside that interval:

\[ w(x)= \begin{cases} \left(\dfrac{x}{x_m}\right)^{a}, & x<x_m,\\ 1, & x_m\leq x\leq x_s,\\ \left(\dfrac{x_s}{x}\right)^{b}, & x>x_s. \end{cases} \]

For demand, (a=1.2) and (b=2). For labour, (a=b=10). These functions are schematic assumptions rather than calibrated physiological or economic schedules.

Code 
age_weight <- function(
  age,
  lower_age = 15,
  upper_age = 45,
  young_exponent,
  old_exponent
) {
  case_when(
    age < lower_age ~
      (age / lower_age)^young_exponent,

    age > upper_age ~
      (upper_age / age)^old_exponent,

    TRUE ~ 1
  )
}

age_weights <- tibble(age = 0:100) |>
  transmute(
    age,
    `Subsistence demand` = age_weight(
      age,
      young_exponent = 1.2,
      old_exponent = 2
    ),
    `Labour contribution` = age_weight(
      age,
      young_exponent = 10,
      old_exponent = 10
    )
  ) |>
  pivot_longer(
    -age,
    names_to = "weighting",
    values_to = "weight"
  )

3.6 Reproducibility notes

  • The Peristera–Kostaki implementation is shared by fertility and union formation, but each process and sex can use a separate parameter set.
  • The Coale–Demeny code uses demogR version 0.6.0, the version used to generate the NetLogo lookup tables.
  • The mortality plots visualise the baseline annual probabilities before any density-dependent increment is added.
  • The demand and labour functions are deterministic model assumptions. Their role is to make population composition consequential for total demand and effective capacity, not to reproduce a measured universal age profile.
  • Plot labels and captions use the terminology adopted in the manuscript: subsistence demand, labour contribution, nominal environmental capacity, and labour-adjusted effective capacity.
